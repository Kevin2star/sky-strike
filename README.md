# SKY STRIKE

북쪽을 향해 날아오르는 2D 비행기 슈팅 게임입니다. 3개의 스테이지를 지나 각 스테이지 끝의 보스를 쓰러뜨리면 GAME CLEAR입니다. HTML, CSS, JavaScript만으로 만들었고 별도 설치나 이미지 파일이 필요 없습니다.

**플레이**: https://dbqkwhc099b0s.cloudfront.net

## 게임 방법

### 조작
| 키 | 동작 |
|---|---|
| ← ↑ → ↓ | 이동 |
| SPACE | 발사 (누르고 있으면 연사) |
| P | 일시정지 |
| Enter | 시작 / 재시작 |

### 라이프
- 큰 라이프 3개(♥)가 있고, 각 큰 라이프마다 작은 라이프가 5칸 있습니다.
- 적의 공격에 맞으면 작은 라이프가 깎입니다.
- 작은 라이프가 모두 없어지면 기체가 폭발하고 큰 라이프가 1개 줄어듭니다. 큰 라이프가 남아 있으면 다시 나타납니다.
- 큰 라이프가 모두 없어지면 GAME OVER입니다.
- 피격 직후와 재등장 직후에는 잠시 무적이며 기체가 깜빡입니다.

### 적
소형, 중형, 대형이 있고 클수록 체력과 공격력이 높습니다.

| 종류 | 공격력(작은 라이프) | 특징 |
|---|---|---|
| 소형 | 1 | 지그재그로 내려오며 조준탄을 쏩니다 |
| 중형 | 2 | 2발씩 조준탄을 쏩니다 |
| 대형 | 3 | 5방향 탄을 쏩니다 |

### 보스
- 스테이지 끝마다 보스가 나오며 화면 위에 체력바가 표시됩니다.
- 스테이지 1, 2 보스는 체력이 절반 아래로 내려가면 변신하고 2페이즈 패턴이 시작됩니다.
- 최종 보스(스테이지 3)는 3페이즈입니다. 1페이즈에서 2페이즈로는 체력 50%에서 넘어가고, 2페이즈 체력이 0이 되면 3페이즈로 변신하면서 체력이 100%로 다시 찹니다.
- 변신하는 동안 보스는 무적입니다.

### 아이템
적을 처치하면 낮은 확률로 떨어집니다. 보스를 쓰러뜨리면 `+`와 `P`가 하나씩 확정으로 나옵니다.

| 아이템 | 효과 |
|---|---|
| 초록 `+` | 작은 라이프 1칸 회복 |
| 주황 `P` | 공격력 강화 (총알 수 증가, 최대 5단계) |
| 빨강 `♥` | 큰 라이프 1개 회복 (아이템이 나올 때 1% 확률) |

기체가 폭발하면 공격력이 1단계 내려갑니다.

### 난이도
생각보다 많이 어렵습니다. 스테이지 2부터 보스가 회전 탄막을 쏘고, 최종 보스 3페이즈에서는 회전 탄막, 조준탄, 위에서 쏟아지는 탄을 한꺼번에 피해야 합니다. 피격 판정은 기체 중심의 작은 점에만 있으니 탄이 지나갈 틈을 보고 움직이세요.

## 로컬 실행
`game/index.html`을 브라우저에서 열면 됩니다. 서버가 필요하면 다음 명령을 쓸 수 있습니다.

```bash
cd game && python3 -m http.server 8765
```

## AWS 배포
`terraform/`에 S3(비공개)와 CloudFront(OAC) 구성이 있습니다.

```bash
cd terraform
cp terraform.tfvars.example terraform.tfvars   # bucket_name을 전 세계에서 유일한 값으로 수정
terraform init
terraform apply
```

완료되면 `website_url`에 HTTPS 주소가 출력됩니다. 게임 파일을 고친 뒤 `terraform apply`를 다시 실행하면 바뀐 파일만 업로드됩니다.
